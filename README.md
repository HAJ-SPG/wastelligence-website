# Wastelligence Webseite

Webseite von Team Wastelligence (Paul Fiala, Julia Hammerschmidt und David Kutis). Wir entwickeln Lösungen, mit denen Mülltrennung einfacher wird. Unser erstes Projekt ist SortIQ, ein Mistkübel, welcher den Müll mit einem KI-Modell erkennt und selbst ins richtige Fach sortiert. SortIQ entsteht als Diplomprojekt an der HTL Spengergasse in Wien.

Die Seite ist unter [wastelligence.com](https://wastelligence.com) erreichbar.

## Aufbau

Die Webseite besteht nur aus HTML und CSS, ohne Build-Schritt, Cookies oder externe Schriftarten.

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite |
| `impressum.html` | Impressum und Datenschutz |
| `style.css` | Gestaltung und Farben |
| `assets/` | Logo, Renderings und Animation |

Zum Ansehen reicht es, `index.html` im Browser zu öffnen. Gehostet wird die Seite über GitHub Pages.
